# Audio sources and licences

Everything in `Game/Assets/StreamingAssets/Audio` was made for this project (the fight theme is the user's own tune, see the table). **No free sound library, sample pack or recording is used, as a placeholder or otherwise.**

| What | Where it comes from | Licence / terms |
|---|---|---|
| **Music** (the four loops, the six stings, victory, failure, death) | Composed as MIDI by the audio builder agent (`audio_src/compose/*.py` writes `audio_src/midi/*.mid`), rendered by our own synthesiser (`tools/audio/Synth`, plain C#, no samples) | Ours. Original composition; the 80s palette (Vangelis, Tangerine Dream, Carpenter, Mass Effect 1) is a direction, nothing is quoted or copied |
| **The fight theme** (`music/fight.mp3`, 4.9 MB) | **The user's own music**: `audio_src/user_music/Monolith_Epic_1.mp3` (3:29), committed by the user as their mission theme and shipped unchanged (no re-encode) with its loop points, start and level written in `music/music.json` (`audio_src/music.json`, `shipped`); the tools (`tools/audio/analyse_track.py`) only measured it | The user's |
| **Theme tracks** (the Lector, the destroyer, the outpost) | Composed as MIDI and rendered by our synthesiser like the rest of the music (`audio_src/compose/themes.py`) | Ours |
| **Sound effects** (guns, hits, explosions, beams, engine, alarms, jump flash, Earth's horn, interface) | Synthesised in code (`tools/audio/Sfx`) from oscillators, noise, modal and FM synthesis and our own reverbs. No recordings | Ours |
| **Radio voices** (diaspora crews and wingmen, the alien ally, Earth) | Generated by **Breeze-TTS-2** (`BreezeBlue/Breeze-TTS-2` weights, run through the `breeze-tts` runtime that Trap Door's `tools/tts/01..03` scripts installed under WSL `~/breeze`; we read from that install and changed nothing in Trap Door). Voices are **designed from text descriptions** (`audio_src/voice/cast.json`: age, accent, delivery; accents used: South African, neutral American (Tamsin), Australian, London, Texan, Northern English, none for Earth, alien for Wick; **no Scottish and no Irish accent anywhere**), seed 42, each line asked for at its intensity (calm, tense or frantic); **no real person is named, imitated or cloned**, and no reference recordings are used. The raw lines are then put through our radio filter (`Dsp/Radio.cs`) | **The Breeze weights and everything generated with them are for non-commercial use only** (the same terms as Trap Door's voices). The files in `StreamingAssets/Audio/vo` are therefore non-commercial. The user's own recordings replace them one by one (see `Audio/README.txt`), and the pipeline can be pointed at another voice model |
| **Encoding** | `ffmpeg` with libvorbis (installed on the build machine; not distributed) | The encoded files are ours |
| **Code** | Our own. No third-party audio code is vendored (Unity's built-in decoder reads the OGG and MP3 files; Newtonsoft.Json is already a project package) | n/a |
| **Design references** | The user's own earlier work, read only: Star Frog's `AUDIO.md` (a C# synth, songs as data, drop-in MP3/WAV/OGG overrides) and Trap Door's voice pipeline (`tools/tts`, `design/VOICES.md`) | Ours |

If a free (CC0) library is ever used as a placeholder, it goes in this table with its URL, licence and the files it made, and in the commit that adds it.

Sizes (2026-10-24, audio round 3): music 15.9 MB (17 files: the 13 above, the three synthesised themes, and the user's fight theme at 4.9 MB), effects 6.6 MB (89 cues, 158 files), radio voices 5.5 MB (174 clips): **28.0 MB in total** (OGG Vorbis at 48 kHz; the effect loops are stored as WAV so their seams are sample-exact). The encoder runs bit-exact (`-fflags +bitexact`) and every render is deterministic, so remaking unchanged sound changes no bytes.
