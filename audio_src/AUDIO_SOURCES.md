# Audio sources and licences

Everything in `Game/Assets/StreamingAssets/Audio` was made for this project. **No free sound library, sample pack or recording is used, as a placeholder or otherwise.**

| What | Where it comes from | Licence / terms |
|---|---|---|
| **Music** (the four loops, the six stings, victory, failure, death) | Composed as MIDI by the audio builder agent (`audio_src/compose/*.py` writes `audio_src/midi/*.mid`), rendered by our own synthesiser (`tools/audio/Synth`, plain C#, no samples) | Ours. Original composition; the 80s palette (Vangelis, Tangerine Dream, Carpenter, Mass Effect 1) is a direction, nothing is quoted or copied |
| **Sound effects** (guns, hits, explosions, beams, engine, alarms, jump flash, Earth's horn, interface) | Synthesised in code (`tools/audio/Sfx`) from oscillators, noise, modal and FM synthesis and our own reverbs. No recordings | Ours |
| **Radio voices** (diaspora crews and wingmen, the alien ally, Earth) | Generated by **Breeze-TTS-2** (`BreezeBlue/Breeze-TTS-2` weights, run through the `breeze-tts` runtime that Trap Door's `tools/tts/01..03` scripts installed under WSL `~/breeze`; we read from that install and changed nothing in Trap Door). Voices are **designed from text descriptions** (`audio_src/voice/cast.json`: age, accent, delivery; accents used: South African, Irish, Australian, London, Texan, Northern English, none for Earth, alien for Wick; **no Scottish accent anywhere**), seed 42, each line asked for at its intensity (calm, tense or frantic); **no real person is named, imitated or cloned**, and no reference recordings are used. The raw lines are then put through our radio filter (`Dsp/Radio.cs`) | **The Breeze weights and everything generated with them are for non-commercial use only** (the same terms as Trap Door's voices). The files in `StreamingAssets/Audio/vo` are therefore non-commercial. The user's own recordings replace them one by one (see `Audio/README.txt`), and the pipeline can be pointed at another voice model |
| **Encoding** | `ffmpeg` with libvorbis (installed on the build machine; not distributed) | The encoded files are ours |
| **Code** | Our own. No third-party audio code is vendored (Unity's built-in decoder reads the OGG and MP3 files; Newtonsoft.Json is already a project package) | n/a |
| **Design references** | The user's own earlier work, read only: Star Frog's `AUDIO.md` (a C# synth, songs as data, drop-in MP3/WAV/OGG overrides) and Trap Door's voice pipeline (`tools/tts`, `design/VOICES.md`) | Ours |

If a free (CC0) library is ever used as a placeholder, it goes in this table with its URL, licence and the files it made, and in the commit that adds it.

Sizes (2026-10-24): music 7.7 MB (13 files), effects 5.5 MB, radio voices 5.2 MB (156 clips: 36 calm, 50 tense, 70 frantic): **18.7 MB in total** (OGG Vorbis at 48 kHz; the effect loops are stored as WAV so their seams are sample-exact). The encoder runs bit-exact (`-fflags +bitexact`) and every render is deterministic, so remaking unchanged sound changes no bytes.
